## 🧰 Tech Stack
- **Frontend:** React.js + Tailwind CSS  
- **Backend:** Node.js + Express.js  
- **Database:** MongoDB Atlas  
- **Hosting:** Netlify (Frontend) + Render (Backend)

## 🧩 Features Implemented
- 🟢 **User Authentication** (Student/Teacher roles)
- 🟢 **Course Management**
- 🟢 **Enrollment System**
- 🟢 **Assignment Uploads**
- 🟢 **Grading Dashboard**
